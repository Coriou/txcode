# Notifications

Tx Code can show system alerts, play sounds, or show in-app notifications when a thread finishes, fails, or needs input or approval. They are off by default.

In **Settings → General**, choose **Thread notifications** to enable system alerts, sound, or both. The browser asks for notification permission when you enable system alerts. If permission was denied, allow notifications in your browser or operating system settings.

Choose which events show system alerts using the completion, failure, approval, and input controls. **Alert focus** determines whether they appear always, only when the app is unfocused, or also when you are viewing another thread. Sounds and in-app notifications have their own controls.

Existing notification preferences carry forward when upgrading. Choosing Off keeps notifications off across restarts. Clicking a notification opens its thread. Browser alerts replace the previous alert for the same thread; archived threads and subagents do not produce these alerts.

Mobile push notifications use the mobile app's relay notification settings and are independent of these controls.
